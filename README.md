## 🛠️ Tecnologías Utilizadas
* **Diseño UI/UX:** Prototipos interactivos aplicados al código.
* **Maquetación Estática:** HTML5 semántico y CSS3 estructurado (Modular y Responsive).
* **Dinamismo e Interacción:** JavaScript Vanilla (ES6+), manipulación del DOM, menú responsive, interactividad en Vista Detalle y validación de formularios.

## 📂 Estructura Modular de Archivos
* **📁 assets/**: Recursos multimedia e imágenes del proyecto.
* **📁 components/**: Fragmentos HTML reutilizables (`header.html`, `footer.html`).
* **📁 css/**: Hojas de estilo independientes para cada sección (`style.css`, `carrito.css`, `contacto.css`, etc.).
* **📁 pages/**: Vistas de la aplicación (`catalogo.html`, `detalle.html`, `carrito.html`, `contacto.html`).
* **📁 scripts/**: Lógica de programación (`functions.js`, `contact.js`).

## 🚀 Despliegue e Instalación Local
1. Clona el repositorio desde la rama de desarrollo:
   ```bash
   git clone -b dev https://github.com
   ```
2. Abre el proyecto en tu editor de código.
3. Ejecuta el archivo raíz mediante un servidor local (ej. *Live Server* en VS Code).
